# KaivosAI - Game Command Reference
## Command-Line Interface (CLI) Syntax v2.0

### About Game Commands
**KaivosAI** features a natural language command-line interface for controlling robots, managing objects, and operating the game world. Commands support full words and short aliases for efficient gameplay.

### Design Philosophy
- Natural language command structure (verb-based)
- Short aliases for frequent commands (r, c, d, m)
- TAB completion support
- Real-time feedback and error messages
- Hierarchical command organization (system, map, robot)

---

## Command Reference

### Robot Control Commands

**robot ID goto X Y [d N]**
- Move robot to coordinates (X, Y)
- Optional: d N = stop N cells away from target
- Aliases: `r ID g X Y [d N]`
- Example: `robot 1 goto 10 15`
- Example: `r 1 g 10 15 d 2` (stop 2 cells away)
- Example: `r 2 g 5 8` (move adjacent to position)

**robot ID goto OBJ_ID [d N]**
- Move robot adjacent to object with ID
- Optional: d N = stop N cells away from object
- Aliases: `r ID g OBJ_ID [d N]`
- Example: `robot 1 goto 5`
- Example: `r 1 g 5 d 3` (stop 3 cells away from object 5)
- Note: Without distance parameter, robot stops 1 cell away (adjacent)

**robot ID load [amount]**
- Load materials from adjacent object (mine/storage/base/robot)
- If amount omitted, loads until robot is full
- Aliases: `r ID l [N]`, `r ID ld [N]`
- Example: `robot 1 load` (load all possible)
- Example: `r 1 l 3` (load exactly 3 materials)
- Requires exactly one adjacent source object
- Transfer rate: 1 material/second

**robot ID unload [amount]**
- Unload materials to adjacent object (storage/base/robot)
- If amount omitted, unloads entire inventory
- Aliases: `r ID u [N]`, `r ID ul [N]`
- Example: `robot 1 unload` (unload all)
- Example: `r 1 u 5` (unload exactly 5 materials)
- Requires exactly one adjacent destination object
- Transfer rate: 1 material/second

**robot ID code**
- Open RoboBASIC editor for robot code
- Aliases: `r ID c`, `r ID code`, `r ID prg`, `r ID prog`
- Example: `robot 1 code`
- Example: `r 2 c` (short form)
- Editor controls:
  - F2: Save program and exit editor
  - ESC: Cancel and discard changes
  - Arrow keys: Navigate
  - Type 'help' in editor for RoboBASIC syntax
- Max 20 characters per line
- See robot_programming_syntax.txt for programming language details

**robot ID start**
- Start executing robot's RoboBASIC code
- Aliases: `r ID s`, `r ID start`, `r ID run`, `r ID execute`
- Example: `robot 1 start`
- Example: `r 1 s`
- Robot status changes to RUNNING
- Program executes one command per tick

**robot ID pause**
- Pause robot code execution
- Aliases: `r ID p`, `r ID pause`, `r ID stop`, `r ID halt`
- Example: `robot 1 pause`
- Example: `r 1 p`
- Robot status changes to IDLE
- Program execution paused at current line

### Object Management Commands

**create TYPE X Y**
- Create new object at position (X, Y)
- Aliases: `c TYPE X Y`
- Types: robot, mine, storage, base
- Example: `create robot 5 10`
- Example: `c mine 12 8`
- Example: `c storage 15 15`
- Example: `c base 20 20`
- Objects get unique sequential IDs
- Position must be unoccupied
- Default names: "Robot", "Mine", "Storage", "Base"
- Default capacities:
  - Robot: inventory 5, produces nothing
  - Mine: produces 1/10s, capacity 10
  - Storage: capacity 20
  - Base: consumes 1/10s, capacity 20

**delete ID**
- Remove object by its ID number
- Aliases: `d ID`, `del ID`, `rm ID`
- Example: `delete 5`
- Example: `d 3`
- Removes object from map and database
- ID is freed for reuse (use 'system optimize' to renumber)

**delete X Y**
- Remove object at coordinates (X, Y)
- Aliases: `d X Y`, `del X Y`, `rm X Y`
- Example: `delete 10 15`
- Example: `d 12 8`
- Removes whatever object is at that position
- Error if position is empty

### Movement & Inspection Commands

**move X1 Y1 to X2 Y2**
- Move object from (X1,Y1) to (X2,Y2)
- Alternative syntax: `move X1 Y1 X2 Y2` (no "to")
- Aliases: `mv X1 Y1 to X2 Y2`
- Example: `move 5 10 to 7 12`
- Example: `mv 3 3 5 5`
- Target position must be unoccupied
- Does not validate pathfinding (direct teleport)

**inspect X Y**
- Show object information at position
- Example: `inspect 10 15`
- Example: `inspect 5 8`
- Returns object name and type at position
- Returns "Nothing at (X,Y)" if empty

### Map Operations

**map show**
- Show map in left panel
- Aliases: `map`, `m`
- Example: `map show`
- Example: `m`
- Note: Map is always visible in panel
- Command exists for completeness

**map list**
- Show all objects in right panel
- Aliases: `map ls`
- Example: `map list`
- Example: `map ls`
- Note: Objects panel always visible
- Shows: ID, name, position, status, inventory/materials

**map terrain [density] [size]**
- Generate random rock terrain
- Aliases: `map t [density] [size]`
- Example: `map terrain` (default: 0.05 density, size 3)
- Example: `map t 0.1 5` (10% rocks, clusters of 5)
- Example: `map terrain 0.03 2` (3% rocks, clusters of 2)
- Parameters:
  - density: 0.0-1.0 (default 0.05 = 5% of map)
  - size: cluster size 1+ (default 3)
- Generates border rocks + random interior clusters
- Does not overwrite existing objects

**map demo**
- Add 4 demo objects at random positions
- Example: `map demo`
- Creates:
  - 1 Robot (random position)
  - 1 Mine (random position)
  - 1 Storage (random position)
  - 1 Base (random position)
- Uses strong randomization (time + os.urandom)
- Useful for quick testing

**map reset**
- Clear entire map and reset game clock
- Example: `map reset`
- Removes all objects from map and database
- Resets game time to 0
- Resets clock to W1 D1 00:00:00
- Cannot be undone!

### System Commands

**system pause**
- Pause game clock
- Aliases: `pause` (legacy)
- Example: `system pause`
- Example: `pause`
- Stops time progression
- Stops all production/consumption
- Robot programs continue to execute at paused rate

**system resume**
- Resume game clock
- Aliases: `resume` (legacy)
- Example: `system resume`
- Example: `resume`
- Resumes time progression
- Resumes production/consumption
- Robot programs continue at normal rate

**system optimize**
- Renumber object IDs sequentially
- Example: `system optimize`
- Reorganizes IDs to 1, 2, 3, 4...
- Useful after many deletions
- Updates all references and database
- Does not change object positions or properties

**system version**
- Show KaivosAI version number
- Aliases: `version` (legacy)
- Example: `system version`
- Example: `version`
- Returns current version (e.g., "0.12.22")

**system help**
- Show command help text
- Aliases: `help` (legacy)
- Example: `system help`
- Example: `help`
- Displays all available commands
- Shows aliases and shortcuts

**system quit**
- Exit game and close TUI
- Aliases: `quit` (legacy), ESC key
- Example: `system quit`
- Example: `quit`
- Saves all state to database before exit
- Can also press ESC to quit

## Command Aliases Reference

### Robot Shortcuts
- `r` = `robot`
- `g` = `goto`
- `l` = `load`
- `ld` = `load`
- `u` = `unload`
- `ul` = `unload`
- `c` (after `robot ID`) = `code`
- `prg` / `prog` (after `robot ID`) = `code`
- `s` (after `robot ID`) = `start`
- `p` (after `robot ID`) = `pause`
- `bot` = `robot`

### Object Management Shortcuts
- `c` = `create`
- `d` = `delete`
- `del` = `delete`
- `rm` = `delete`
- `mv` = `move`

### Map Shortcuts
- `m` = `map`
- `t` = `terrain` (in map context)
- `ls` = `list` (in map context)

### System Shortcuts
- `pause` = `system pause`
- `resume` = `system resume`
- `help` = `system help`
- `version` = `system version`
- `quit` = `system quit`

## Example Command Sequences

### Example 1: Basic Setup
```
create robot 5 5       ; Create robot at (5,5)
create mine 10 10      ; Create mine at (10,10)
create storage 15 15   ; Create storage at (15,15)
map terrain 0.05 3     ; Add terrain (5% rocks)
```

### Example 2: Manual Robot Control
```
r 1 g 10 10            ; Move robot 1 to mine position
r 1 l                  ; Load materials from mine
r 1 g 15 15            ; Move to storage
r 1 u                  ; Unload materials to storage
```

### Example 3: Programming Robot
```
r 1 c                  ; Open editor
; Type program:
; :START GOTO 10 10
; LOAD
; GOTO 15 15
; UNLOAD
; GOTO :START
; Press F2 to save
r 1 s                  ; Start program execution
```

### Example 4: Inspection & Cleanup
```
inspect 10 10          ; Check what's at position
d 5                    ; Delete object with ID 5
d 12 12                ; Delete object at position (12,12)
system optimize        ; Renumber remaining IDs
```

### Example 5: Using Shortcuts
```
c robot 3 3            ; Create using 'c' alias
c mine 8 8
r 1 g 2                ; Move robot 1 to object 2
r 1 l 5                ; Load 5 materials
r 1 g 10 10 d 2        ; Go to (10,10), stop 2 away
```

### Example 6: Managing Game State
```
pause                  ; Pause clock
inspect 5 5            ; Inspect while paused
resume                 ; Resume clock
map reset              ; Clear everything (careful!)
map demo               ; Add demo objects
```

## Display Panels

### Map Panel (Left)
- 30x30 grid with coordinates
- Object symbols:
  - R = Robot (light cyan)
  - M = Mine (yellow)
  - S = Storage (light green)
  - B = Base (light magenta)
  - # = Rock (dark gray)
- Shows robot paths with ~ markers
- Auto-centers on objects

### Objects Panel (Right Top)
- Lists all objects with:
  - ID number
  - Name (10 chars max)
  - Position (X,Y)
  - Status/Progress bar
  - Inventory or materials
- Format examples:
  - Robot: `R  1 Robot      @( 5, 5) [===.......] 3/5`
  - Mine: `M  2 Mine       @(10,10) [=====.....] 5/10`
  - Storage: `S  3 Storage    @(15,15) [====......] 8/20`
  - Base: `B  4 Base       @(20,20) [=.........] 2/20`

### Events Panel (Right Middle)
- Recent game events (max 10)
- Format: `[HH:MM:SS] event description`
- Auto-scrolls to show latest

### Clock Panel (Right Bottom)
- Current game time
- Format: `W# D#  HH:MM:SS`
- Example: `W1 D1  12:34:56`
- 1 game week = 7 game days
- 1 game day = 24 game hours

## Command Line Features

### TAB Completion
- Press TAB to auto-complete commands
- Works for command names and aliases
- Example: type `rob` + TAB → `robot`

### Command History
- Use UP/DOWN arrows to navigate history
- Previous commands recalled for editing
- History persists during session

### Error Messages
- Clear feedback on invalid commands
- Suggests correct syntax on errors
- Example: `"Usage: robot ID goto X Y"`

### Natural Language Parsing
- Flexible word order in some cases
- Case-insensitive (ROBOT = robot = Robot)
- Handles extra whitespace
- Quotes supported for future extensions

## Tips & Best Practices

1. **Use Shortcuts**: `r 1 g 5 5` is faster than `robot 1 goto 5 5`
2. **Check First**: Use `inspect X Y` before creating objects
3. **Program Complex Tasks**: Use RoboBASIC for repeated actions
4. **Save Before Reset**: `map reset` cannot be undone
5. **Optimize IDs**: Run `system optimize` after many deletions
6. **Use Distance**: `r 1 g 10 10 d 2` keeps robots from clustering
7. **Default Amounts**: Omit amount in load/unload to transfer max
8. **Pause for Edits**: `pause` while setting up complex scenarios
9. **Watch Events**: Events panel shows what robots are doing
10. **Test Programs**: Test robot programs on single robot first

## Common Workflows

### Mining Setup
```
1. map terrain 0.05 3     ; Generate terrain
2. c mine 10 10           ; Place mine
3. c storage 15 15        ; Place storage
4. c robot 5 5            ; Create robot
5. r 1 c                  ; Open code editor for robot loop
6. r 1 s                  ; Start automation
```

### Manual Hauling
```
1. r 1 g 2                ; Go to mine (ID 2)
2. r 1 l                  ; Load all available
3. r 1 g 3                ; Go to storage (ID 3)
4. r 1 u                  ; Unload all
5. repeat steps 1-4       ; Or automate with program
```

### Cleanup & Restart
```
1. pause                  ; Stop time
2. d 1                    ; Delete unwanted objects
3. d 5
4. system optimize        ; Renumber IDs
5. resume                 ; Resume time
```

### Testing & Debugging
```
1. map demo               ; Quick test objects
2. r 1 g 2                ; Test movement
3. r 1 l                  ; Test loading
4. inspect 10 10          ; Check positions
5. map reset              ; Clean slate
```

## Object Types Reference

### Robot (R)
- **Purpose**: Mobile worker for material transport
- **Capacity**: 5 materials (inventory)
- **Production**: None
- **Consumption**: None
- **Special**: Can execute RoboBASIC programs
- **Commands**: goto, load, unload, code, start, pause
- **Display**: `R ID Name @(X,Y) [progress] inv:N/5`

### Mine (M)
- **Purpose**: Produces raw materials
- **Capacity**: 10 materials
- **Production**: 1 material per 10 seconds
- **Consumption**: None
- **Special**: Stops producing when full
- **Commands**: Can be loaded from by robots
- **Display**: `M ID Name @(X,Y) [progress] mat:N/10`

### Storage (S)
- **Purpose**: Central material warehouse
- **Capacity**: 20 materials
- **Production**: None
- **Consumption**: None
- **Special**: Accepts deposits and withdrawals
- **Commands**: Can load from or unload to robots
- **Display**: `S ID Name @(X,Y) [progress] mat:N/20`

### Base (B)
- **Purpose**: Consumes materials for operations
- **Capacity**: 20 materials
- **Production**: None
- **Consumption**: 1 material per 10 seconds (when available)
- **Special**: Stops consuming when empty
- **Commands**: Can be loaded from or unloaded to by robots
- **Display**: `B ID Name @(X,Y) [progress] mat:N/20`

### Rock (#)
- **Purpose**: Terrain obstacles
- **Capacity**: None
- **Production**: None
- **Consumption**: None
- **Special**: Blocks movement, pathfinding routes around
- **Commands**: delete only (no create via command - use map terrain)
- **Display**: `# in map, not in objects list`

## Error Messages Reference

### Robot Commands
- `"Robot ID not found"` - No robot with that ID exists
- `"No adjacent objects to load from"` - Robot not near source
- `"Multiple adjacent objects"` - Too many objects nearby (move away)
- `"Not enough inventory"` - Robot doesn't have enough to unload
- `"Target full"` - Destination object at capacity
- `"No program defined"` - Trying to start empty program

### Object Management
- `"Position occupied"` - Can't create, something already there
- `"Invalid object type"` - Type must be: robot, mine, storage, base
- `"Nothing at (X,Y)"` - Can't delete, position is empty
- `"Object ID not found"` - No object with that ID

### Movement
- `"Target position occupied"` - Can't move, destination blocked
- `"Position out of bounds"` - Coordinates outside 0-29 range
- `"No path found"` - Pathfinding failed (blocked by rocks)

### System
- `"Clock already paused"` - Already paused
- `"Clock already running"` - Already resumed
